# SW_0010 — 동료 spike 연결 임계값을 낮춰 조각 수 줄이기

Status: validation sweep complete; no core training or production-code change. Lower thresholds hurt all three metrics.

## 쉽게 설명하면

SW_0008의 개선 후보는 물체가 이미지당 약 31개로 너무 잘게 나뉩니다.
동료 classifier에서 두 patch를 연결하는 기준을 조금 느슨하게 하면
같은 물체의 조각들이 합쳐질 수 있습니다. 그래서 다른 설정은 그대로
두고, 검증 데이터에서 연결 임계값만 낮춰 테스트합니다.

## 정확한 조건

- SW_0004 graph-teacher seed-0 10-epoch checkpoint를 그대로 사용.
- 동료 `patch_v2:5a29422`의 실제 component spike 기반 signed correlation,
  4개 성분의 양의 동기화 곱, 연결 성분 grouping, 최대 성분을 배경 처리.
- 256 step 중 초기 64 제외. 임계값 0.01/0.05/0.10/0.20/0.30/0.40/0.50.
- CLEVR HDF5 검증 ID 1320–1639, 공통 16×16 patch 평가.
- 정답은 점수 계산에만 사용. 같은 reference test ID 1000–1319를 임계값
  선택에 사용하지 않음. 다만 이전 SW_0009에서 reference의 과분할을
  이미 관찰했으므로 완전히 untouched test라는 주장은 하지 않음.

**해석:** 기준을 낮추자 조각 수는 줄었지만 세 점수가 모두 내려갔습니다.
따라서 과분할을 단순히 연결 임계값으로 해결할 수는 없습니다. 한
물체의 조각만 합치는 것이 아니라 서로 다른 물체도 합쳐진다는 뜻으로
해석할 수 있습니다. 0.05/0.20/0.40을 포함한 정확한 수치는
`results.json`에 있습니다. 이번에는 새 설정을 채택하지 않습니다.
