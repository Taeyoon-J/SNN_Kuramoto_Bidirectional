# SW0105: auxiliary-only event detach

This matched continuation tests one gradient-routing change. The core still computes and recurrently uses its original binary event and gate tensors, and its forward output remains the historical `event * gate`. Only the positive spike auxiliary uses `event.detach() * actual_gate`; the objective coefficient stays 5. No event function, reset path, membrane/gate computation, classifier, threshold, or inference prediction was changed.

The candidate starts from each SW0095 final core and matches its SW0097 frozen control on the 4,096 training IDs, shuffle seeds 117/118/119, 256 Adam updates, B16, T64/settle32, LR 3e-5 and clip 1. Encoder and graph stay frozen. Dendritic and membrane tensors are expected to remain bitwise fixed because neither the phase primary nor the detached event auxiliary sends gradients into them. All matched source hashes and training IDs are checked before work starts.

Before training, per-seed preflight compared tracing-off and tracing-on actual forward values, checked exact event-times-gate reconstruction and unchanged affinity/loss values, matched the candidate values and parameter gradients to the direct reference expression, checked finite gradients and a real B16 update, and verified that only expected upstream trainable parameters moved. All three seed preflights passed. Evaluation uses the original event-times-gate spikes on IDs1320-1639, B8/T1024/settle512, classifier threshold .50, minimum group size 2 and largest-component background. No held-out IDs are used for selection.

All three 256-update histories and candidate checkpoints completed before a post-launch owner audit found another user's experiment processes on GPUs0-3. The workers overlapped that process window. Their outputs and ownership evidence are preserved; the existing completed seeds were not retrained. Later, the owner-aware evaluation-only queue ran on free GPUs0-2, with no foreign owners detected and no training restart. Each result contains 320 valid images from IDs1320-1639, using the original B8/T1024/settle512/.50 actual-spike classifier; predictions did not use ground truth.

SW0105 mean scores were `.776264/.576342/.601518` (FG-ARI/foreground IoU/object IoU). Against the matched SW0097 frozen controls, the mean deltas were `-.000085/-.000729/-.000020`; seed0 improved slightly, while seeds1 and2 were lower on all three metrics. Against SW0092 matched Slot epoch10 means `.774933/.203589/.206937`, SW0105 was higher on all three means, though its FG-ARI was lower than Slot for seeds1 and2. The event-detach auxiliary therefore shows no reliable improvement over its matched frozen controls and is not advanced. The small 320-image Slot comparison does not establish independent 70k superiority or complete the broader goal; independent confirmation and a 70k encoder/graph run remain pending. The training GPU-overlap limitation remains part of this result's provenance. Per-seed values, paired deltas, validation checks, and SHA-256 provenance are in [`evaluation_summary.json`](results_archive/evaluation_summary.json); the terminal evaluation queue record is in [`queue_state.json`](results_archive/queue_state.json).

This intervention isolates explicit output-factor gradient credit; it does not remove every event-dependent internal path, and any outcome does not resolve feature/graph data-scaling questions. Detailed preflight, training history, evaluation, and provenance are archived under `results_archive/`. Candidate weights remain on the server and are not committed.
