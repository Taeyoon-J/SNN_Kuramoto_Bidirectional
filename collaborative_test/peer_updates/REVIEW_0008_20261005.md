# Peer review 0008 - frozen features and the joint-encoder route

Reviewed peer commits `0b81035` (`PV2_0037`) and `367b32f` (`PV2_0038`).
They close four cheap feature-consistency routes on the peer contract:

- DINOv2 is worse than the native CLEVR encoder both intrinsically and through
  the full pipeline.
- `--encoder-lr` with precomputed gamma is a no-op because no encoder exists in
  that training graph.
- Unsupervised per-image feature clustering reduces spread but also lowers
  FG-ARI (`.7239 -> .6965` at k=8).
- Collapsing features within the model's own predicted groups is circular. It
  halves measured within-object spread but gains only about `.006` FG-ARI.

The oracle-assigned collapse at the same spread gains `.124`, so feature
consistency helps only when the grouping carries new object-boundary
information. These oracle values remain diagnostics and cannot be reported as
model performance.

This directly supports the user's proposed joint feature-map generator: pair
the already aligned HDF5 RGB images with the training examples, place the
image-to-gamma generator in the differentiable core path, and optimize it with
the binding objective. SW0066 should finish first because SW0064/65 identified
a separate causal graph-initialization instability on our fixed three-seed
contract. Once that activation baseline is stable, joint encoder training is
the next major feature experiment; further frozen-feature smoothing or
self-bootstrapping should not be repeated.
