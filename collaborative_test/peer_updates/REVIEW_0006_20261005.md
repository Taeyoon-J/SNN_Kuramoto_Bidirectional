# Peer review 0006 - feature ceiling evidence

Reviewed peer commits `084a2ef` and `96d74d6` from `origin/patch_v2`.

The peer's fixed 300-image, three-seed diagnostic reports that true object
count does not rescue the real-feature affinity: spike affinity with true count
scores FG-ARI `.6360`, below connected components at `.7059`. Even phase
affinity with true count reaches only `.7338`. This supports moving effort away
from count/readout tuning.

The stronger oracle replaces gamma features with ground-truth object-constant
codes while leaving the architecture and scoring path in place. Spike scoring
then reaches FG-ARI `.9754`, foreground IoU `.7748`, and matched-object IoU
`.7533`; real features are `.7059/.6778/.4903`. This isolates feature quality as
a major bottleneck and shows the SNN/Kuramoto path can exceed the target when
its input separates objects.

The oracle uses labels and is diagnostic only. It cannot be reported as model
performance. The actionable transfer is to train or replace the feature
encoder without changing the fixed validation contract. The peer's end-to-end
encoder experiment `PV2_0033` is still marked running, so its outcome must be
reviewed before duplicating or porting that training recipe.
