# SW0103 single-pass triangle-supported spike readout

This fixed validation-only diagnostic applied the reviewed readout rule once to the three matched SW0097 frozen cores: construct the actual positive-product spike classifier `q`, threshold at `.50`, symmetrize by OR with a false diagonal, keep edges with at least one common neighbor, and restore the original edge only for raw connected components of exactly two patches. It uses no iteration, RGB cue, object count, threshold tuning, or model update. All six raw/triangle prediction sets were constructed before the validation labels were read.

The actual raw classifier output reproduced the archived SW0097 per-image scores exactly for all three seeds and all three metrics (maximum absolute score difference 0). The triangle rule failed the predeclared 16-image gate, so the conditional full320 follow-up was not run. Mean cross-instance coassignment fell `.027603→.026014`; mean same-instance coassignment recall fell only `.00185`, and no image acquired zero predicted groups where raw had groups. Both IoU margin checks over the Slot means pass; the gate fails only on its FG-ARI requirements.

Seed-level scores, exact baseline checks, per-image coassignment, foreground patch loss, object-induced graph fragmentation, removed edge classes and removed raw-graph bridges are in `results_archive/first16.json`.
