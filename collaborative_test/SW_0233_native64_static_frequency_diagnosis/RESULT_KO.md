# SW0233: 고정 위치 frequency가 주된 병목이라는 근거는 약함

accepted SW0223의 고정16장·세 seed 캐시를 원본 checkpoint와 대조해 CPU에서 분석했다. 추가 학습이나 모델 실행은 없었다. 로컬·Linux의 세 검사가 모두 통과했고, 분산 분해 오차는 최대 3.47e-18이다.

물체별로 평균을 제거한 실제 frequency의 변동과 정적 omega 성분의 변동은 다음과 같다. 배경도 하나의 class로 포함하며 class별 동일 가중치다.

| seed | 원래 전체 변동 | 학습 후 전체 변동 | 고정 omega 변동 |
|---|---:|---:|---:|
| 0 | .005064 | .003360 | .000216 |
| 1 | .017437 | .013505 | .000550 |
| 2 | .007019 | .005320 | .000465 |

고정 성분의 크기는 원래 전체 변동의 약 3.2–6.6%, 학습 후의 약 4.1–8.7%다. 이는 원인 기여율이 아니다. 정적 성분과 encoder 입력 성분 사이 공분산도 별도로 계산했으며, 음수 공분산은 서로 상쇄할 수 있다.

이 표본에서는 encoder 입력 성분의 변동이 훨씬 크다. 따라서 omega를 풀거나 위치별 상수를 바꾸는 것을 다음 최우선 실험으로 삼을 근거는 부족하다. 현재 SW0232에서 원래 teacher objective의 실제 이어 학습 효과를 먼저 확인한다. 이 진단만으로 고정 graph 문제, 데이터 증가 효과, gating의 인과적 기여를 입증하거나 배제하지 않는다.
