# SW0100 phasor-imaginary raw gate (preparation)

This experiment tests one opt-in mode, `phasor_imag_raw`, on matched whole SW0095 seed 0/1/2 final cores. Its delayed scalar membrane mask is `0.5 * (1 + mean_d(sin(theta_delayed[..., d])))`; dendritic drive remains `sin(theta_current) * mask[..., None]`. The existing `raw` implementation and default are unchanged. No componentwise phase folding, graph, loss, classifier, temporal window, learning rate, or encoder adaptation is introduced.

## Registered pilot plan

Use Adam for 256 updates, batch 16, exactly the 4,096 SW0097 `positive_frozen` training IDs in the same per-seed order, shuffle seeds 117/118/119, 64 training steps with settle 32, core LR `3e-5`, gradient clip 1, and the unchanged primary objective plus 5x positive-product spike synchrony loss. Freeze encoder and graph; initialize each seed from its whole SW0095 final core. Compare with the completed matched SW0097 frozen controls and verify source checkpoint hashes, ordered training IDs, and all unchanged hyperparameters. Evaluation uses IDs 1320-1639, original batch 8, 1024 steps/512 settle, fixed `.50` spike classifier, largest-component background, and existing patch metrics.

Before training, require static checks and the focused gate tests. The coordinator first compares raw/new-mode actual-source CPU forwards (batch 2, 64 steps) for all three SW0095 cores with graph feedback and spike pulses disabled; graph, theta, and `sin(theta)` carrier must be exactly equal. It then runs one actual-data CPU forward/backward/update preflight per source seed. Each must load the source state strictly, produce finite loss and gradients, update the trainable core, and leave graph and encoder bitwise exact. The coordinator also verifies that the 4,096 ordered IDs, source SHA, shuffle, update count, batch, learning rate, and training window match SW0097. The implementation includes the preflight, queue guard, full-320 completion checks, and fixed 16-image raw/mode swap traces; no training queue has been launched.

The zero-update diagnostic applies raw versus the new mode to each SW0095 source on the fixed SW0099 16-image subset, then applies raw to each completed candidate on the same images. It records actual gate/drive variance, a component-sine cancellation index, fixed-threshold endpoint scores, and actual spike pair AUC/separation in near/mid distance bins. These are representation checks only; they are not used to choose a gate or tune a setting. If the pilot improves the balanced three-seed mean and FG-ARI and matched-object IoU improve in at least two seeds, inspect near/mid distance-controlled gated-drive and spike pair AUC on full evaluation. Otherwise do not expand to full 70k training. A clear three-seed endpoint loss stops this exact recipe.

The implementation defaults to legacy `raw`; only SW0100 passes `--gate-mode phasor_imag_raw`. `test_phasor_imag_raw_gate.py` covers independent phase lifts, component permutation, D=1, exact cancellation, legacy exactness, unchanged state-dict structure, and finite gradients. The coordinator may use one independent seed per genuinely free GPU among 0-3 and never shares an occupied device. Registration and implementation are not results.
